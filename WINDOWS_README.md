See **README.md** and **READ_ME_FIRST.md** for current setup and build instructions. The searchable **USER GUIDE** and **assets/User_Guide.html** describe all controls and format behavior.

Build Mac App.command builds the Mac app; Create GitHub Release.command creates local Mac release assets. Build-Windows.ps1 and .github/workflows/windows-build.yml build the Windows x64 ZIP. Builds run automated tests and packaged runtime checks. They do not upload or publish releases. Test the output on its target platform before distributing it.
